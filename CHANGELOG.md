# Changelog

## 0.1 — 2026-11-11 — Initial proposal

- Define a portable build contract with ten Markdown sections and JSON metadata.
- Embed prompts for orientation, building, verification, recovery, and amendment.
- Trace binding requirements and constraints to observable acceptance checks.
- Separate draft/readiness, structural validity, and verified implementation.
- Define explicit input references, revision changes, evidence identity, and
  authority boundaries.
- Include a comprehensive template, two complete example contracts, authoring and
  integration guidance, primary-source research, and proposal-review rationale.
- Provide a dependency-free structural linter, regression tests, and GitHub CI.

This is a proposal release prepared for publication. Native agent integrations
and independent application-build trial results are not part of this release.
